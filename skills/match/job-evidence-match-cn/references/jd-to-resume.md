# JD 识别与已有简历定向优化

在用户核对 JD 后即可启动此流程。匹配分数不是前置条件。

1. 输入可以是粘贴的文字、单张截图或同一岗位的多张截图。先转录截图原文，保留顺序、数字、单位、否定与“或／优先”等限定。模糊处标待核对。提取公司、职位原称、职责、明确必需项及加分项。来源缺失时留空。对不同岗位的截图分别建档；同岗多图合并并去重。每项在界面可对照原文纠正。
2. 核对页右下角显示“据此去优化简历”。点击保存核对后的 JD 修订，弹窗列出已有工作稿和已归档修订，显示名称、修订号与示例身份。选中哪份，就以该份当时的正文和版式生成副本。没有底稿时引导导入。
3. 以目标岗位要求选择原简历中已有的行动、判断和交付，优先前置相关要点或调整句式。同一条经历可突出不同侧面。职责、数字、指标口径、归属、阶段、教育、证书、工具和实习日期须有原稿支撑。仅凭 JD 或词库出现的词不得写为候选人能力。缺证据时保留原稿，待用户主动补充。
4. 返回按原文本框 ID 定位的改写清单。只改正文，保留格式、位置与其他用户改动。相同目标反复生成也保留先前底稿。写入新稿时保留来源简历 ID／修订与目标 JD ID／修订。保存成功再进入简历优化台，用户能继续改和导出；取消、过期或处理失败可重新选择，不提前跳转。
5. 对照验收：JD 同时含“每周至少三天”和“SQL 优先”，两者分别进入必需项、加分项。原稿若只有“协助两个团队试用”，投递渠道运营时仍须保留协助及试用阶段。旧稿原句、样式和修订应可重开。
