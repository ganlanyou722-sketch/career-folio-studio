# 已确认的中文求职简历版式

用于复现已认可的一页中文互联网产品经理简历。以下数值是排版基准；新任务中用户明确指定的改变优先。没有特别要求时，保留字体、字号、行距及页边距，优先通过内容取舍解决容量问题。

## 单位与页面

- 全部数值使用 pt；1 pt = 1/72 英寸。
- 纵向 A4，当前模板采用 **595 × 842 pt** 的取整尺寸。
- 左边界 **x = 30**，右边界 **x = 565**，左右页边距均为 **30 pt**（约 10.58 mm），正文可用宽度 **535 pt**。
- 本文的 `top` 表示距页面顶端的距离。PDF 底部原点换算：`y = 842 - top`。
- 内容末端距页底至少 **27 pt**，内容充实的一页参考目标约 **30 pt**；这是底部留白，不是页脚高度。
- 正文段落文字颜色为 **#111111**；直接绘制的条目标题、日期、姓名、联系行及分隔线为黑色。无装饰色块、评分条、技能进度条和额外页眉小字。

注意：英文和数字切换 Arial 的规则用于正文段落。姓名、联系行、各类条目标题以及右侧日期／奖项沿用微软雅黑，包括其中的英文和数字。不要将“正文英文用 Arial”扩大为整页所有英文均用 Arial。正文中的英文或数字落在加粗范围内时，必须切到 **Arial Bold**，避免视觉上丢失强调。

Windows 字体参考文件为 `msyh.ttc`、`msyhbd.ttc`（均使用第 0 个字形集合）、`arial.ttf`、`arialbd.ttf`。不在分享包中复制商业字体。其他系统使用合法可用的同款字体路径；确实无法取得时说明差异，再选择替代字体并重新验证，不能静默替换后声称完全一致。

## 页首架构

- 姓名水平居中于页面，即 **x = 297.5**；不另加目标岗位的小字。
- 联系方式使用一行自然排布，字段只保留用户提供的信息；不要补造电话、微信、邮箱或地址。
- 有照片时，联系行以 **x = 276** 为中心；照片放在右侧 **x = 522、top = 5.3**，尺寸 **43 × 62.7**，底边位于 **top = 68**。
- 无照片时省去照片，可将联系行以页面中心居中；保留其字号与基线位置。
- 照片仅使用用户提供的材料，等比缩放置入照片框并靠下对齐；不拉伸人物。框内最大宽 43 pt、高 62.7 pt，实际图像比例不同时允许留白。
- 教育背景栏目行框从 **top = 50.5** 开始。这一值与姓名、联系行、照片位置共同构成页首，不能把姓名基线误当成统一上页边距。
- 联系行过长时先去掉低价值字段或减少无意义空格，检查与照片的实际边界，不能直接缩小全页字体。

## 栏目标题与分隔线

默认顺序：**教育背景 → 实习经历 → 项目经历 → 竞赛荣誉 → 技能／语言**。有充分理由时可按岗位和资历调整栏目顺序，保留视觉层级。

每个栏目按同一算法定位：

1. 标题行框高 **18 pt**，标题字号 **15.02 pt**、加粗。
2. 令标题行框下沿为 `end`，分隔线位于 **`top = end + 1`**，从 **x = 30** 画到 **x = 565**，线宽 **0.65 pt**。
3. 第一条内容从 **`top = end + 6`** 开始。
4. 后续栏目标题的起点为前一内容块末端 **+2 pt**。首个教育栏目按页首的 **50.5 pt** 定位。

## 实习与项目条目

- 左侧采用“公司／项目名称｜团队或产品｜角色”，右侧日期右对齐至 **x = 565**。
- 实习标题 **9.96 pt**；项目标题 **9 pt**；右侧日期均为 **9 pt**。标题与日期在同一条基线上。
- 令条目起点为 `top`、左侧字号为 `size`，标题基线为 **`842 - top - size`**。
- 标题行结束后，下一段起点为 **`top + 20.8`**；这是纵向推进值，不是标题文字行距。
- 同栏相邻实习之间、相邻项目之间各画一条 0.65 pt 黑色实线，从 x = 30 至 x = 565。以本段结束位置为 end，横线在 end + 1 pt，下一段从 end + 3 pt 开始。N 段经历对应 N−1 条段间线；首段前、末段后及同一经历的要点之间均不重复画线。
- 不固定给某个比赛或某个项目额外空隙；统一按上述规则排布。
- 标题与日期之间至少预留 **10 pt**；两者宽度之和加 10 pt 必须小于 **535 pt**。
- 长标题先减少重复词、删除非必要括注、调整角色表达，不能覆盖日期或随意缩小该条字号。
- 日期统一 `YYYY.MM - YYYY.MM` 或 `YYYY.MM - 至今`，并核对真实起止时间。

## 正文项目符号与强调

- 项目符号起点 **x = 30**，正文起点 **x = 39**，形成 **9 pt 悬挂缩进**。
- 换行后的文字继续从 **x = 39** 开始；正文行宽 **526 pt**。
- 正文 **9 pt**，固定行距 **17.28 pt**；段内不插入空行。
- 同一条经历的两个 bullet 之间额外增加 **1 pt**；最后一个 bullet 后不重复增加此间隔。
- 每个 bullet 以“**不超过 12 个字的贡献概括：**”开头，紧接背景／任务、个人行动和结果。概括长度不含空格、冒号及格式标记；中英混合时按可见字符计数。
- 概括、少量关键数字／成果可以加粗；不把整段正文加粗。
- 默认左对齐，按真实字体宽度自动换行。正文允许中文换行，避免将完整英文词拆散；不要通过插入空格伪造对齐。
- 优先让多行 bullet 的末行达到正文宽度的一半。末行不足一半是编辑预警：先通过删冗、合并或补充有证据的关键信息调整；不为凑行编造信息。

## 教育与页底

- 教育条目左侧学校／专业／学历，右侧时间或已确认的状态，均 **9 pt 加粗**；每行推进 **17.28 pt**。
- 成绩、排名及少数相关课程使用正文样式，内容必须有来源。
- 竞赛优先选 **3–4 项**，每项占一个独立横向行，左侧完整比赛名称、右侧奖项／级别，均 **9 pt 加粗**，每行推进 **17.28 pt**。
- “横向行”指一项比赛横贯该行，不能误做成四项并列的四列；不为每个奖项增加描述段落。
- 不把“数模一等奖”等简称当完整比赛名，不凭模板补足不存在的奖项。可核验的全称过长时先处理其他低价值信息，再决定受控换行。
- 技能／语言在最后一个竞赛行末端 **+4 pt** 开始，不额外增加大号栏目标题；用正文样式写成简洁一行。
- 英语成绩仅在用户实际提供时保留，成绩数值不写死；技能只列岗位相关且有事实依据的项目。

## 容量调整与验收

- 这套版式默认一页，不能通过缩小正文、压缩固定行距或无限减页边距来容纳新增信息。
- 内容溢出时按岗位相关性删减，先去重复背景、工具堆砌、弱相关描述，再合并同类行动；保留主导贡献、核心方法、结果与口径。
- 页底空白明显过高时，补回能够证明能力的有效行动、方法选择和交付细节；不放大字号、拉大行距或增加泛泛自评来填空。
- 检查完整页：无裁切、无黑块、无字体回退，标题／日期不碰撞，项目符号缩进统一，所选 3–4 个奖项各占一行，技能位于末尾。
- 检查 PDF 仍是一页，文本可选中／搜索，正文中文与英文粗体正确，末端在 **top ≤ 815** 范围内。
- 最终版本必须重新渲染后目视检查。Word 中同名字号和固定行距只能作为迁移起点，字形度量及段落行为可能不同；以导出的 PDF 视觉结果为准。
